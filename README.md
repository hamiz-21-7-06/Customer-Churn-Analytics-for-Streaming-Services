# Customer-Churn-Analytics-for-Streaming-Services
Predicting subscriber churn for streaming services using machine learning and behavioral data. By identifying key drivers like user inactivity, this project implements a tuned Decision Tree model to provide actionable insights. The final solution is deployed as a Flask  app to visualize real-time churn risk and feature importance.

This project demonstrates the complete ML pipeline:

✅ Data preprocessing  
✅ Data Visualization  
✅ Model Building

---

## 📌 Objectives

- Analyze and preprocess streaming service customer churn data
- Visualize the data through matplotlib and seaborn
- Train a Logistic Regression and Decision Tree Model
- Evaluate Model Performance

  ---

## 🧠 Features Used for Prediction

| Feature     | Description |
|-------------|-------------|
| `age`       | Age of the customer. |
| `gender` | Gender of the subscriber (Male, Female, Other). |
| `subscription_type` | The tier of the plan (Basic, Standard, Premium). |
| `watch_hours`    | Total hours spent watching content. |
| `last_login_days`  | Number of days since the last login. |
| `region`  | Geographic location of the customer (e.g., Africa, Asia, Europe). |
| `device`    | Primary device used for streaming (TV, Mobile, Laptop, etc.). |
| `monthly_fee`   | The amount paid by the user per month. |
| `payment_method`   | Method used for billing (Gift Card, Crypto, PayPal, etc.). |
| `number_of_profiles`  | Number of individual user profiles under one account. |
| `avg_watch_time_per_day`    | Average daily viewing duration in hours. |
| `favorite_genre`    | The genre most preferred by the user (Action, Sci-Fi, etc.). |
| `churned`    | Indicates if the customer has cancelled the subscription (1/Yes or 0/No). |
